# Flow — Version 1.2.0

## Overview
After 1.1 establishes fluid interactions and Liquid Glass refinement, 1.2.0 expands canvas capability and editor robustness.

---

## Core Focus Areas

### 1. Rich Text Expansion
- Font size, family, color selection
- Text alignment (left, center, right, justify)
- List support (bulleted, numbered)
- Links & code formatting
- Strikethrough & highlight
- Text object persistence & collaboration readiness

### 2. Canvas Object Management
- Multi-select & batch operations
- Grouping/ungrouping objects
- Layer management (bring to front, send back, z-order)
- Alignment tools (snap-to-grid, distribute evenly)
- Undo/redo stack refinement

### 3. Advanced LaTeX
- Equation library/templates
- Symbol palette
- MathML export
- Inline vs. block equation modes
- Equation manipulation (rotate, reflect, annotate)

### 4. Drawing & Annotation Enhancements
- Pressure sensitivity & pen smoothing
- Shape recognition (auto-straighten lines, detect circles/rectangles)
- Freehand shape tools (polygons, callouts)
- Eraser modes (segment erase vs. clear all)
- Vector stroke optimization

### 5. File & Collaboration
- Local save/export (PNG, SVG, PDF)
- Share via link (read-only preview)
- Import PDF onto canvas

### 6. Elements Expansion
- Energy Orbital Diagrams (Chemistry)
- etc.

### 7. Performance & Polish
- Canvas rendering optimization
- Tool layout customization
- Memory profiling & cleanup
- Keyboard shortcuts & accessibility
- Dark mode support
- Mobile responsiveness refinement
